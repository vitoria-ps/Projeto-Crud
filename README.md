# Sistema de Biblioteca — Java Swing + MySQL + MVC

Projeto acadêmico de CRUD desenvolvido em Java com Swing, MySQL e arquitetura MVC.

## Funcionalidades
- Cadastrar livro
- Visualizar livros cadastrados
- Editar livro selecionado
- Excluir livro selecionado

## Requisitos
- JDK 17+
- MySQL 8+
- Maven


## Executar
Na pasta do projeto:
Duplo clique no arquivo 'rodar'

# Sistema de Biblioteca — Java Swing + SQLite + MVC

Projeto acadêmico de CRUD desenvolvido em Java com Swing, SQLite e arquitetura MVC.

## Funcionalidades
- Cadastrar livro
- Visualizar livros cadastrados
- Editar livro selecionado
- Excluir livro selecionado

## Requisitos
- Java
- JavaSwing
- SQLite

Duplo clique no arquivo 'rodar'
